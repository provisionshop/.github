 [!IMPORTANT]
> **Migrate to TrustVC by 31 March 2027**
>
> All new OpenCerts must be issued using TrustVC, IMDA's supported open-source framework aligned with the W3C Verifiable Credentials standard. Existing OpenAttestation (OA) credentials remain valid and verifiable.
>
> OpenCerts is maintained by IMDA. OA has been deprecated since 1 October 2025.
>
> 📘 [Migration guide](https://docs.opencerts.io/docs/migrations/oa_to_trustvc)
